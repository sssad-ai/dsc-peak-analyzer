# DSC 分析工具

一个本地运行的 Python 工具：读取 DSC Excel / 文本表格，绘制曲线，分析峰温、事件焓、玻璃化转变和表观结晶度。

## 项目解决什么问题

仪器导出的 DSC 表格可能带有多行说明、不同单位、倒序时间和多个扫描阶段，直接对温度曲线求面积容易误算焓。本项目将导入、阶段排序、可见基线、时间积分和材料条件输入放在同一界面，并保留计算参数，方便复现。

v0.1 使用规则与信号处理，不需要训练数据。默认熔融和冷却结晶温区适用于 PP；分析其他材料时应调整温区。不能把这个默认范围称为通用材料识别模型。

## 主要功能

- 导入 `.xlsx`、`.xls`、`.csv`、`.txt`、`.tsv`、`.dat`；读取 NETZSCH 元数据和非首行表头。
- 按仪器段号/扫描程序恢复 H1 → C1 → H2 → C2，也支持单段数据。
- 原始曲线、候选峰、基线、积分区域和四阶段叠加；提供峰温、峰高、半显著性宽度和主峰切线 onset/endset 估算。
- 自动建议积分范围，可调整分析温区、基线方法和积分边界；焓按原始热流与时间计算。
- 升温段 Tg 台阶中点估算；无法支持结果时说明具体原因。
- 可选结晶度计算：用户自行输入基体名称、质量分数、完全结晶参考熔融焓和同段冷结晶修正。没有预设牌号或组成推断。
- 下载汇总 CSV、分析 ZIP 和离线交互 HTML；可选在 ZIP 中附带归一化原始数据。
- 一组四阶段合成示范数据，不包含企业实验数据或派生结果。

## 安装方法

需要 Python 3.10+；NumPy 2.0+。从项目根目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Linux/macOS：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

Git 用于版本管理，不是运行分析工具的前提。

## 使用方法

Windows 双击项目根目录的 `start.cmd`，或直接运行：

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Linux/macOS：

```bash
.venv/bin/python -m streamlit run app.py
```

打开 <http://127.0.0.1:8501>。服务器只监听本机；保持启动窗口打开，关闭它后服务停止。已关闭首次运行邮箱提示和 Streamlit 使用统计。

默认显示合成演示。使用自己的数据时，在左侧选择上传文件，或主动填写本机样品根目录。每个样品放一个子目录、每个扫描段放一份表格。Excel 的 `~$` 临时文件自动忽略；原文件不会被修改。

1. **曲线与峰**：选择阶段，查看主峰温度、焓和曲线。需要时展开“调整温区与积分”，让分析温区两端落在峰外基线区。
2. **玻璃化转变 Tg**：默认最后一次升温，可调整温区。Tg 是热容台阶而不是普通峰；未覆盖温区或拟合证据不足会保留空值。
3. **结晶度（可选）**：开启后填写基体名称、基体占整个试样的质量分数、参考焓。分别选择无冷结晶（采用 0）或输入同一升温段的冷结晶焓。所有材料输入默认留空。
4. **下载结果**：位于底部折叠区。ZIP 保存参数、来源摘要、基线和峰表；只有勾选“附带归一化原始数据”才包含该份原始数值。没有复核表单或复核状态。

## 输入示例

普通表至少需要温度和热流，推荐带时间；表头标明单位：

```csv
Temperature (°C),Time/s,Heat Flow (W/g)
30.0,0.0,0.281
30.1,0.6,0.282
30.2,1.2,0.283
```

上面三行只说明列格式，分析需足够采样点。NETZSCH 表头之前的 `#FILE`、`#SEGMENT`、`#RANGE`、`#EXO` 等无需删除。未知单位或没有放热方向时，可在导入设置手动指定。无时间列时须填写恒定扫描速率，否则无法计算焓。

完整示范只有以下四个 CSV，均由数学公式生成：

| 文件 | 阶段 |
|---|---|
| `examples/synthetic_pp_gf/synthetic-H1.csv` | 首次升温 |
| `examples/synthetic_pp_gf/synthetic-C1.csv` | 首次降温 |
| `examples/synthetic_pp_gf/synthetic-H2.csv` | 二次升温 |
| `examples/synthetic_pp_gf/synthetic-C2.csv` | 二次降温 |

生成逻辑见 `examples/generate_demo.py`：直线背景、Gaussian 峰及 sigmoid 台阶，不读取实验输入、不拟合企业曲线。可用 `python examples/generate_demo.py` 重新生成。

## 输出示例

对随附合成示范、使用默认参数时得到近似结果（非真实材料测试值）：

| 阶段 | 主峰温度 °C | 事件焓 J/g试样 | Tg 中点估算 °C |
|---|---:|---:|---:|
| H1 | 166.03 | 90.14 | —，未覆盖低温范围 |
| C1 | 118.00 | 63.10 | —，降温段不分析 Tg |
| H2 | 163.00 | 71.36 | -8.00 |
| C2 | 118.00 | 63.10 | —，降温段不分析 Tg |

`summary.csv` 包含各阶段峰、焓、可选结晶度及 Tg 状态。ZIP 还包含 `analysis.json`、每段的 `_peaks.csv` 和 `_baseline_curve.csv`。缺失数值保留空值，不填 0 或猜测值。

例如，手动设置合成示范基体为 PP、质量分数 60%、参考焓 209 J/g、H2 无冷结晶，H2 表观结晶度约为 `71.36 / (0.60 × 209) × 100% = 56.91%`。这些是操作示例输入，不是软件的预设材料信息。参考焓应根据实际材料与晶型选择。

## 计算逻辑和限制

- 热流统一为 W/g试样；mW/mg 数值与 W/g 相同，不重复除以样品质量。时间 min 转为 s。
- 平滑曲线用于寻峰；原始热流扣线性基线后按时间积分得到 J/g。多峰事件组只积分一次，目前没有分配每个重叠峰的独立焓。
- `Xc = (ΔHm − ΔHcc) / (w_matrix × ΔHm0) × 100%`。ΔHcc 必须来自同一升温段，不能用 C1/C2 冷却结晶焓替代。
- Tg、切线温度、自动边界和结晶度都依赖分析条件。合成测试通过不代表真实材料准确率，也不代表完整 ISO/ASTM 方法符合性。
- PP 研究中采用 209 J/g 的实例见 [参考论文](https://matsc.ktu.lt/index.php/MatSc/article/view/30947/15873)；程序不自动填写此值。

## 数据隐私

仓库和源码包仅含一组合成四阶段数据，不含企业原始表、物性 PDF、实测结果、批次/牌号、仪器截图或个人路径。应用没有主动上传数据到第三方的实现，默认只监听本机。

本地导出可能含敏感文件名、仪器元数据、数值和文件摘要，应作为私有实验资料保管，不要直接公开。`.gitignore` 排除数据、导出、日志、缓存和密钥，仅放行四个合成 CSV。它不能替代对新代码和文档的人工检查。
