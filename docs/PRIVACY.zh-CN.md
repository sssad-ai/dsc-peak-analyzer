# 隐私与发布说明

## 本次公开版本检查

检查过源码、文档、示例、配置、导出与截图。

- 原文档中的本机绝对路径、企业样品名称和实测数值已移出公开项目。
- 企业派生 CSV/JSON、报告、截图、来源清单和日志已备份到项目外。
- 默认页面使用合成示范，不自动寻找私人数据目录。
- 示例仅保留一个样品的 H1/C1/H2/C2 四个数学 CSV，旧单段示例已移出。
- 公开文件中未发现有效密码、访问 Token、私钥或个人邮箱。
- 公开发布仅推送通过检查的源码、文档与合成示例，企业资料不在 Git 跟踪内容中。

Git 提交使用项目署名与本地占位邮箱，避免写入个人姓名、邮箱。运行环境与 Git 配置不包含在源码发布包中。

## 后续新增文件

`python scripts/check_public_files.py` 检查不应公开的文件类型、绝对用户路径和常见凭据模式；可在暂存之后加 `--staged` 检查实际暂存文件。检测只报告文件、行号和规则名称，不输出可能的秘密值。

`.gitignore` 拒绝 Excel、PDF、图片、数据、导出、日志、缓存、密钥、环境文件和非示范 CSV。公开数据白名单只有四个合成文件。

自动检查不能证明所有未来内容都无机密。实验文件名、来源摘要、仪器操作者和数值即使没有密码也可能敏感；添加文档或示例前应确认内容允许公开。MIT 许可证仅适用于本仓库的代码、文档与合成示例。
