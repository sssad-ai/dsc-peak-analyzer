# 项目设计与实现逻辑

目标是把 DSC 表格整理、可视化和材料计算整合为简单、可解释的本地工具。本版采用规则与科学信号处理，无机器学习训练。

## 界面

三个页签：曲线与峰、玻璃化转变 Tg、结晶度（可选）。基线、积分设置、峰表、阶段叠加和下载放在折叠区。没有复核流程或牌号列表。材料名称只标识数据，不推断组成。

默认打开一组合成四阶段数据。读取本机目录须用户主动输入；上传数据保存在应用会话中，程序不将原文件自动复制进代码仓库。

## 引擎

| 文件 | 职责 |
|---|---|
| `parser.py` | 表头、单位、时间、仪器段号、来源摘要；忽略 Excel 临时文件 |
| `analysis.py` | 基线、寻峰、边界、原始时间积分、切线温度 |
| `materials.py` | 用户输入的组成、参考焓和冷结晶修正 |
| `tg.py` | 两基线台阶拟合与具体不可用原因 |
| `plots.py` | 曲线、峰、基线、积分图形 |
| `export.py` | CSV、ZIP 和离线 HTML |
| `batch.py` | 本机目录批量分析，无牌号推断 |
| `app.py` | 界面与参数输入 |

pandas/openpyxl 读表，NumPy/SciPy 做积分和拟合，Plotly 画交互图，Streamlit 提供界面。SHA-256、参数和基线随结果导出，用于复现。旧 `peaks.py` 仅保留早期接口，其 FWHM 温度面积不作为当前焓计算。

## 数据与隐私

仓库只包含数学生成的四个示范 CSV。没有企业数据、派生结果、材料 PDF、个人路径或本地截图。原始企业数据与内部验证记录保存在仓库外，不适用本项目 MIT 软件许可证。

`.gitignore` 排除数据、导出、密钥、日志、图片、PDF、Excel 和缓存，仅放行四个明确的合成 CSV。忽略规则不能识别未来粘贴到源代码中的机密内容，新增文件提交前仍需执行公开文件检查。

## 选择及限制

基线与积分边界可以调整，因为自动范围对基线漂移敏感。Tg 独立使用热容台阶模型；未覆盖温区、基线交叉、信号弱、拟合边界和方向不符会明确显示。结晶度由用户填写基体、质量分数和参考焓，没有默认材料数值。

当前限制是线性基线、PP 默认搜索区间、未分配重叠峰独立焓、真实 Tg 尚无公开独立真值集。后续优先做基线敏感性和公开标注数据对照，再考虑保存完整会话或机器学习。
