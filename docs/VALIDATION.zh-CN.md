# 公开版验证记录

验证环境：Python 3.14、NumPy 2.4.6、pandas 3.0.3、SciPy 1.18.0、Streamlit 1.58.0。公开版仅附一组合成样品的 H1/C1/H2/C2 四个 CSV，不附企业实测数据、名称、文件摘要、图片或派生数值。

## 可复现测试

运行 `python -m pytest -q`。测试包括：

- 高斯峰解析面积与原始时间积分结果对照，检查 J/g 单位和降温符号。
- 两峰事件组只积分一次，不重复累加重叠面积。
- W/g、mW/mg、mW/g、mW、W 单位换算。
- 人工构造 NETZSCH 元数据、表头、降温倒序时间和阶段排序。
- 未知单位、重复时间、缺少必要参数的错误处理。
- 结晶度质量分数、同段冷结晶修正和基体质量基准。
- 数学 Tg 台阶恢复、纯直线拒绝、反向台阶说明、窄温区初始化以及热容符号。
- 不修改源数据；导出参数和文件摘要；原始数据仅在主动勾选时附带。
- 页面无牌号预设、材料输入为空、结晶度重算和积分调整。

合成示范文件由 `examples/generate_demo.py` 使用明确的直线、高斯峰和 sigmoid 公式生成，不读取实验文件、不拟合企业测量曲线。示范数据用于功能和计算检查，不能代表真实材料准确率。

## 结果适用范围

目前没有可公开的独立实测真值集。不会在公开文档中报告企业样品数值、牌号、批次或截图对照结果。数学测试通过不能证明真实 Tg 已准确识别，也不能证明完整 ISO/ASTM 标准符合性。

仍需独立验证跨仪器适配、复杂基线、重叠事件、真实 Tg 标注、逐峰焓和参考焓/组成测量误差。对于无法支持的结果，程序保留空值并说明原因。
